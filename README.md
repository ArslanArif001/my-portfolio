# Arslan Arif - Portfolio

Modern portfolio website built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build Static Site

```bash
npm run build
```

This generates a static site in the `out/` directory. Deploy the `out/` folder to any static hosting service.

Preview locally:
```bash
npm run preview
```

## Important Notes

- Static assets must be in `public/assets/` folder
- Images are optimized with Next.js Image component
- Dark mode preference is saved in localStorage

## Tech Stack

Next.js 14 | TypeScript | Tailwind CSS | Framer Motion
